# Gravitációs Erő Szimulátor

Interaktív fizikai szimulátor Newton gravitációs törvénye alapján.

## Funkciók

- Gravitációs erő számítása
- Valós idejű grafikon
- Űr animáció
- Tudományos számformátum
- Reszponzív modern felület

---

## Technológiák

- Next.js
- React
- TypeScript
- Tailwind CSS
- Chart.js
- Motion

---

## Fizikai képlet

F = G × (m₁ × m₂) / r²

A gravitációs erő a tömegekkel egyenesen, a távolság négyzetével fordítottan arányos.

---

## Indítás

```bash
npm install
npm run dev
```
